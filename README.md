# Openai standalone paper trading study

Completed, testable paper-research version of the owner's older standalone MetaTrader/LLM experiment, kept separate from NexusAI. The original laptop script is preserved. This version corrects the false 50-bar moving average, accepts NO_TRADE, validates structured responses, recomputes reward/risk, rounds position sizes down, enforces 1% intended risk per trade/three open positions/3% aggregate intended risk, accounts for configurable margin and fees, and records paper entries/exits. It has no broker connection or live-order function.

Run `python openai_api.py` for a deterministic offline demonstration, or `python openai_api.py --data market.csv --output paper_results.json` for a local OHLC replay. Output files cannot overwrite existing files. Install Python 3.12 or later; no external dependency is required. Run `python -m unittest discover -v` for stress tests.

CSV columns: `time,symbol,open,high,low,close`. Timestamps must be ISO 8601 with a timezone, strictly increasing per symbol. OHLC values must be finite and positive. Signals see only past/current closed bars; entries occur at the current close and exits begin on subsequent bars. If stop and target are both touched, the stop wins; stop gaps fill at the worse open. Open positions stay explicitly marked at the end of a replay.

With your own configured `OPENAI_MODEL` and `OPENAI_API_KEY`, the explicit `--provider openai` option sends price summaries to that provider. Set an available model supporting the documented request format. Provider keys and account access were not used in validation: request/response transports are tested with mocks. The default demo performs no network request. Real provider calls can incur charges. All results remain paper-only.

The minimum bracket ratio is 1.5:1. `--point-value` means account currency per full price unit per position unit, not an inferred pip value. Supply the correct instrument/account conversion, unit step, margin and round-trip fee yourself. Default units are synthetic; the program does not discover broker contract specifications. Intended stop risk is not a guaranteed loss ceiling: gaps can exceed it. The 3% drawdown gate applies to the replay session, not a daily reset. Spreads, liquidity and slippage beyond opening gaps are not modeled. Synthetic profits establish no predictive ability or live profitability.

Provider references: [OpenAI structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses), [Groq Chat API](https://console.groq.com/docs/api-reference), [Claude Messages](https://platform.claude.com/docs/en/api/messages/create). API transports and invalid/incomplete responses are exercised locally; live integrations remain unverified. Credentials, model files, market exports, pictures and videos are excluded.
